# 쥬나 아틀리에

롤꾸와 핸드아웃 디자인을 찾아 편집하고 Roll20에 복사하거나 이미지로 저장하는 무료 웹 도구입니다.

- 공식 사이트: https://atelier.zyuna.link/
- 다운로드와 업데이트 내역: https://github.com/zyuna-atelier/atelier/releases

이 저장소는 실행 가능한 배포 파일을 제공합니다. GitHub Pages로 운영하지 않습니다.

## 다운로드한 파일 실행

Releases의 `atelier.zip`을 풀어 HTTPS 정적 호스팅의 루트에 올립니다. `index.html`, `assets`, `database` 등 파일과 폴더의 상대 위치를 유지해 주세요. 서버는 `/`에서 `index.html`을 제공해야 합니다.

개인 컴퓨터에서 확인할 때는 로컬 HTTP 서버를 실행하고 `http://localhost` 주소로 접속해 주세요. 외부 웹 서버에서는 HTTPS를 사용해 주세요. HTML 파일을 더블클릭하는 방식이나 서버의 임의 하위 폴더에서는 정상 동작을 보장하지 않습니다. 디자인 이미지와 웹 폰트는 외부 서비스에서 불러오므로 완전한 오프라인 배포본은 아닙니다.

## 사용 범위

웹 도구 배포 파일은 출처를 유지하면 수정, 자체 호스팅과 무료 재배포할 수 있습니다. **수정본을 재배포할 때는 아래 별도 조건을 지켜야 합니다.** 판매나 유상 재배포는 제작자에게 별도로 문의해 주세요.

- 공식 배포본 전체를 수정 없이 사용하거나 무료 재배포할 때는 디자인과 비밀번호 입력 기능을 그대로 둘 수 있습니다. 유료 디자인은 구매한 본인만 사용할 수 있습니다.
- 파일을 고쳐 혼자 사용하는 것은 수정본 재배포에 해당하지 않습니다.
- 수정해서 다른 사람에게 배포하거나 공개 사이트로 제공할 때는 **쥬나 디자인 데이터(무료, 유료 모두)와 유료 잠금 해제 기능을 빼야 합니다.** 어떤 유료 디자인도 넣을 수 없습니다. 출처를 남기고, 다른 이름과 비공식 표시를 사용하며, 무료로 배포하고 기존 이용 범위도 함께 실어야 합니다.

전체 조건과 수익 활동 제한은 `USAGE.txt`와 앱의 '이용 범위'를 확인해 주세요.

디자인의 이용 조건은 도구와 별개입니다. 무료 디자인에도 각 디자인의 이용 조건이 적용되며, 유료 디자인은 구매 후 사용할 수 있습니다. 도구를 배포할 수 있다는 것이 유료 디자인 원본이나 비밀번호를 공개할 수 있다는 뜻은 아닙니다.

포함된 외부 라이브러리의 고지는 `THIRD_PARTY_NOTICES.txt`에 있습니다.

## 작업 보관과 업데이트

편집한 작업은 사용 중인 브라우저에 저장됩니다. 중요한 작업은 사이트의 백업 기능으로 보관해 주세요. 접속 주소나 브라우저를 바꾸면 기존 작업이 자동으로 옮겨지지 않습니다. 기존 주소에서 백업한 뒤 새 주소에서 복원해 주세요.

새 배포본은 Releases에서 확인할 수 있습니다. 자체 호스팅 사본의 파일 교체는 운영자가 직접 진행해야 합니다. 공식 사이트의 배포 파일 업데이트가 다른 사람이 운영하는 사본에 자동 적용되지는 않습니다.

다운로드한 사본에서도 공식 사이트의 작은 버전 파일을 확인해 새 공식 배포본을 알립니다. 접속할 때 확인하고, 화면을 보고 있는 동안 30분 간격으로 다시 확인합니다. 다른 탭에서 돌아올 때는 마지막 확인 후 5분 이상 지났으면 확인합니다. 통신이 실패해도 작업은 계속할 수 있습니다. 알림의 ‘자세히 보기’에서 Releases를 열 수 있으며 파일은 자동 교체하지 않습니다. 사본 서버에 CSP를 설정한다면 connect-src에서 https://atelier.zyuna.link 연결을 허용해 주세요.

새 디자인 표시는 그 사본 서버의 디자인 목록을 다시 불러왔을 때 이전에 본 목록과 비교합니다. 사본의 파일을 최신 배포본으로 교체해야 새 디자인도 반영됩니다. 기존 사용자 작업을 자동으로 덮어쓰지는 않습니다. 첫 방문에서는 현재 디자인을 모두 본 것으로 기록하므로 NEW 표시를 띄우지 않습니다.
