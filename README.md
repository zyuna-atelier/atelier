# 쥬나 아틀리에

TRPG 세션에 쓸 롤꾸와 핸드아웃 디자인을 찾아 내용을 채우고, Roll20에 바로 복사하거나 이미지로 저장하는 무료 웹 도구입니다. 로그인이나 회원가입 없이 사용할 수 있으며, 개인정보를 요구하지 않습니다. 이 저장소는 실행 가능한 배포 파일을 제공하며, GitHub Pages로 운영하지 않습니다.

## 제작 방식

- 아틀리에는 쥬나(@zyuna_zyuna)가 Claude Code, Codex 같은 AI 코딩 도구를 활용한 **바이브코딩**(AI에게 코드 작성을 맡기고 결과를 확인하며 만드는 방식)으로 제작했습니다. 전문 개발자가 코드를 하나하나 검토하지 않았기 때문에 예상하지 못한 오류가 있거나, 업데이트 후 일부 동작과 화면이 바뀔 수 있습니다. 드물게 오류로 저장된 작업이 사라질 수 있으니 **중요한 작업은 꼭 백업해 주세요.**
- 핸드아웃과 롤꾸 디자인을 만드는 과정에는 **AI 생성물을 사용하지 않았습니다.**
- 포스타입에서 배포 중인 원본 디자인을 아틀리에 규격에 맞게 옮기면서 일부를 조정했습니다(예: 단색 구분선에 장식 추가). 원본 그대로 사용하려면 포스타입의 구글 문서를 이용해 주세요.


## 주요 기능

- **찾기:** 제목, 부제목, 설명, 키워드 검색과 색상, 버전, 유형 필터로 디자인을 찾습니다. 여러 단어를 띄어 쓰면 모든 단어가 들어간 디자인을 찾고, 주소창의 링크로 검색 조건을 공유할 수 있습니다.
- **핸드아웃 편집:** 핸드아웃을 담아 내용을 채우고 Roll20에 복사하거나 PNG, ZIP 이미지로 저장합니다. 같은 디자인을 여러 번 담아도 서로 영향을 주지 않습니다.
- **롤꾸:** 헤더, 구분선, 푸터 명령어를 각각 복사해 Roll20 채팅창에 붙여넣습니다.
- **커스텀 디자인:** 가지고 있는 디자인을 직접 등록하거나, 기본 제공 디자인을 복제해 자유롭게 수정합니다.
- **유료 디자인 잠금 해제:** 포스타입에서 구매한 비밀번호를 입력하면 같은 구매 묶음의 디자인을 한 번에 사용할 수 있습니다.
- **컬러피커와 단축키:** 화면의 색을 집어 복사하고, 검색과 저장, 복사를 단축키로 할 수 있습니다.

자세한 사용법은 사이트 내부의 '이용 가이드'를 확인해 주세요.


## 작업 저장과 백업

- 작업한 내용은 **지금 사용하는 브라우저에만 저장**됩니다. 서버로 전송되지 않으므로 제작자도 확인하거나 복구할 수 없습니다.
- 기기나 브라우저를 바꾸거나 브라우저 데이터를 삭제하면 저장된 내용도 함께 사라집니다. 작업을 마치면 사이트의 **백업**으로 파일을 받아 두세요. 다른 기기나 브라우저에서는 **복원**으로 이어서 작업할 수 있습니다. 복원하면 현재 브라우저의 데이터가 백업 내용으로 교체됩니다.
- 유료 디자인을 담거나 복제했다면 그 내용도 백업 파일에 들어갑니다. **유료 디자인이 담긴 백업 파일은 공개된 곳에 올리거나 다른 사람에게 공유하지 마세요.**
- 비밀번호는 저장하지 않습니다. 잠금 해제 기록은 그 브라우저에만 남고 백업 파일에는 들어가지 않으므로, 다른 기기에서는 비밀번호를 다시 입력해 주세요.
- 접속 주소가 바뀌어도 작업은 자동으로 옮겨지지 않습니다. 기존 주소에서 백업한 뒤 새 주소에서 복원해 주세요.


## 이용 범위 요약

'아틀리에'는 이 웹 도구의 코드와 기능을, '쥬나의 디자인'은 아틀리에에서 제공하는 핸드아웃과 롤꾸 디자인(무료, 유료 모두)을 말합니다. 아래는 요약이며, 전체 조건은 `USAGE.txt`와 사이트의 '이용 범위'가 기준입니다. 이용 범위는 업데이트에 따라 바뀔 수 있으며 사이트의 최신 내용을 따릅니다.

| 가능 | 불가능 |
| --- | --- |
| 개인적인 용도의 TRPG 활동 | TRPG와 관계없는 사용 |
| 완성한 핸드아웃과 롤꾸를 세션에서 사용 | 쥬나의 디자인 재배포(수정본, 일부 발췌 포함) |
| 세션 로그, 후기, 리플레이북에 수록 | 수익이 생기는 모든 활동 |
| 무료 시나리오에 수록(무료 디자인만, 출처 표기) | 유료 디자인을 시나리오에 수록 |
| 내 컴퓨터, 개인 서버에서 실행 | 디자인을 아틀리에용 파일(백업 파일 등)로 판매 |
| 내려받아 혼자 고쳐 쓰기 | 유료 디자인 비밀번호, 데이터 공유와 재판매 |
| 출처 표기 후 코드 참고, 수정, 무료 재배포 | 출처 삭제, 공식 버전처럼 배포 |
| 다른 창작자 디자인을 개인 용도로 등록, 백업 | 다른 창작자 디자인을 허락 없이 수정, 배포 |

- **유료 디자인:** 사용 권한은 구매한 본인에게만 있습니다. 함께 플레이하는 사람에게 비밀번호를 알려 주는 것도 공유에 해당합니다. 유료 디자인으로 완성한 핸드아웃을 세션에서 보여 주는 것은 괜찮습니다. 유료 디자인으로 만든 핸드아웃을 시나리오에 넣으면 받은 사람 모두에게 유료 디자인의 이미지 링크가 전달되므로 수록할 수 없습니다. 유출이 확인되면 아틀리에의 배포를 중단할 수 있습니다.
- **커스텀 디자인:** 커스텀으로 등록된 디자인은 쥬나의 제작물이 아니며, 저작권과 사용 권한은 원래 제작자에게 있습니다. 이용 조건은 원래 제작자의 정책이 우선합니다.


## 출처 표기

- 세션 준비와 진행, 로그 백업, 후기 작성 등 일반적인 사용에서는 출처 표기가 필수가 아닙니다. 핸드아웃 편집의 '출처 표기'를 켜 두면 핸드아웃 아래에 출처가 함께 들어갑니다.
- 무료 시나리오에 완성한 핸드아웃을 넣어 배포할 때는 '쥬나 아틀리에' 출처를 남겨 주세요.
- 아틀리에를 참고하거나 코드, 기능 일부를 가져가 배포할 때는 '쥬나 아틀리에'라는 이름과 주소(<https://atelier.zyuna.link/>)를 꼭 남겨 주세요.


## 배포 파일의 수정과 재배포

웹 도구 배포 파일은 출처를 유지하면 수정, 자체 호스팅과 무료 재배포할 수 있습니다. **수정본을 재배포할 때는 아래 별도 조건을 지켜야 합니다.** 판매, 유상 재배포, 유료 기능 추가 등 수익이 생기는 이용은 허용하지 않습니다.

- 공식 배포본 전체를 수정 없이 사용하거나 무료 재배포할 때는 디자인과 비밀번호 입력 기능을 그대로 둘 수 있습니다. 유료 디자인은 구매한 본인만 사용할 수 있습니다.
- 파일을 고쳐 혼자 사용하는 것은 수정본 재배포에 해당하지 않습니다.
- 수정해서 다른 사람에게 배포하거나 공개 사이트로 제공할 때는 **쥬나 디자인 데이터(무료, 유료 모두)와 유료 잠금 해제 기능을 빼야 합니다.** 본인의 디자인을 포함해 어떤 유료 디자인도 넣을 수 없습니다. 출처를 남기고, 다른 이름과 비공식 표시를 사용하며, 무료로 배포하고 기존 이용 범위도 함께 실어야 합니다.
- 이 저장소를 GitHub 안에서 포크하는 것은 GitHub 이용약관에 따라 허용됩니다. 포크한 저장소를 고쳐 사이트로 게시하거나 다른 곳에 배포할 때는 위 조건을 모두 지켜야 합니다. 수정본의 문의와 유지보수는 수정한 분이 직접 맡아야 합니다.

디자인의 이용 조건은 도구와 별개입니다. 도구를 배포할 수 있다는 것이 유료 디자인 원본이나 비밀번호를 공개할 수 있다는 뜻이 아니므로, 확인 부탁드립니다. 배포 파일에 포함된 외부 라이브러리의 고지는 `THIRD_PARTY_NOTICES.txt`에 있습니다.

## 다운로드한 파일 실행

Releases의 `atelier.zip`을 풀어 HTTPS 정적 호스팅의 루트에 올립니다. `index.html`, `assets`, `database` 등 파일과 폴더의 상대 위치를 유지해 주세요. 서버는 `/`에서 `index.html`을 제공해야 합니다.

개인 컴퓨터에서 확인할 때는 로컬 HTTP 서버를 실행하고 `http://localhost` 주소로 접속해 주세요. 외부 웹 서버에서는 HTTPS를 사용해 주세요. HTML 파일을 더블클릭하는 방식이나 서버의 임의 하위 폴더에서는 정상 동작을 보장하지 않습니다. 디자인 이미지와 웹 폰트는 외부 서비스에서 불러오므로 완전한 오프라인 배포본은 아닙니다.


## 업데이트

새 배포본은 Releases에서 확인할 수 있습니다. 자체 호스팅 사본의 파일 교체는 운영자가 직접 진행해야 합니다. 공식 사이트의 배포 파일 업데이트가 다른 사람이 운영하는 사본에 자동 적용되지는 않습니다.

다운로드한 사본에서도 공식 사이트의 작은 버전 파일을 확인해 새 공식 배포본을 알립니다. 접속할 때 확인하고, 화면을 보고 있는 동안 30분 간격으로 다시 확인합니다. 다른 탭에서 돌아올 때는 마지막 확인 후 5분 이상 지났으면 확인합니다. 통신이 실패해도 작업은 계속할 수 있습니다. 알림의 '자세히 보기'에서 Releases를 열 수 있으며 파일은 자동 교체하지 않습니다. 사본 서버에 CSP를 설정한다면 `connect-src`에서 `https://atelier.zyuna.link` 연결을 허용해 주세요.

새 디자인 표시는 그 사본 서버의 디자인 목록을 다시 불러왔을 때 이전에 본 목록과 비교합니다. 사본의 파일을 최신 배포본으로 교체해야 새 디자인도 반영됩니다. 기존 사용자 작업을 자동으로 덮어쓰지는 않습니다. 첫 방문에서는 현재 디자인을 모두 본 것으로 기록하므로 NEW 표시를 띄우지 않습니다.


## 익명 이용 집계

공식 사이트(<https://atelier.zyuna.link/>)는 방문 수와 기능 사용 횟수를 익명으로 집계합니다. [Umami](https://umami.is/) 클라우드를 사용하며 쿠키를 쓰지 않습니다.

- 수집하는 것: 페이지 방문(주소의 검색어와 `#` 뒤 부분은 빼고 보냄), 새 방문 또는 재방문, 핸드아웃 담기, Roll20 복사(핸드아웃, 롤꾸), 이미지 저장(PNG, ZIP과 개수), 백업과 복원(성공, 실패), 유료 디자인 잠금 해제(성공, 실패, 묶음 이름), 포스타입 링크 이용(디자인 버전). 쥬나가 제공하는 디자인은 디자인 ID를 함께 보내고, 커스텀 디자인은 `custom`으로만 보냅니다. Umami가 기본으로 받는 브라우저 언어, 화면 크기, 이전 페이지 주소, 페이지 제목도 전송되며, Umami는 접속 정보로 브라우저 종류, OS, 기기 종류, 국가 등 접속 지역을 집계합니다. Umami는 수집한 데이터를 익명화하며 개인을 식별할 수 있는 정보는 저장하지 않는다고 밝히고 있습니다([Umami FAQ](https://docs.umami.is/docs/faq)).
- 보내지 않는 것: 핸드아웃 제목과 본문 등 작업 내용, 검색어, 비밀번호, 커스텀 디자인의 제목, 이미지 주소 등 개인이 활용하면서 브라우저에 남는 정보, 백업 파일 내용. 아틀리에는 이름이나 연락처 같은 개인정보를 받지 않습니다. 접속할 때 IP 주소 같은 통신 정보는 Umami 서버에 전달되며, Umami는 수집한 데이터를 익명화한다고 밝히고 있습니다.
- 추적 거부: 브라우저의 추적 거부(Do Not Track) 또는 Global Privacy Control을 켜면 집계 스크립트를 불러오지 않습니다. 광고 차단 등으로 스크립트가 막혀도 사이트는 그대로 동작합니다.
- 배포본: 집계는 공식 주소에서만 동작합니다. 다운로드한 배포본을 다른 주소나 `localhost`에서 실행하면 집계 스크립트를 불러오지 않습니다.
