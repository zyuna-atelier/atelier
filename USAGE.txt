쥬나 아틀리에 웹 도구 배포 파일 이용 안내

제작자: 쥬나 (@zyuna_zyuna)
공식 사이트: https://atelier.zyuna.link/
공식 배포처: https://github.com/zyuna-atelier/atelier

만든 이유
이미 제 디자인을 써 주시는 분들이 원하는 디자인을 빠르게 쓰실 수 있도록, 사용성과
접근성을 다듬어 만든 무료 도구입니다. 넓은 PC 화면부터 모바일까지 편하게 쓰실 수
있도록 만들었습니다.
아틀리에의 모든 기능은 무료입니다. 유료 디자인은 구매하신 분들이 이미지 링크를
하나하나 옮기지 않고 바로 쓰실 수 있도록, 잠금을 걸어 함께 올렸습니다. 판매를 위한
장치라기보다는 구매하신 분들의 편의를 위한 기능입니다.
아래의 제한은 구매하신 분들과 다른 창작자의 유료 디자인이 아틀리에를 통해 퍼지지
않도록 지키기 위한 것입니다.

참고한 도구와 감사
주요 기능과 일부 레이아웃은 휘핑님(@whippyshou)의 '핸드아웃 제작소'를 참고했습니다.
https://www.postype.com/@whippy/post/9334709
아틀리에는 휘핑님의 동의를 받아 제작되었습니다. 좋은 도구를 먼저 만들어 나누어 주시고,
참고할 수 있도록 허락해 주신 휘핑님께 깊이 감사드립니다.

1. 허용 범위
제작자와 공식 사이트의 출처를 유지하는 조건으로 웹 도구 배포 파일을 내려받아
내 컴퓨터나 개인 서버에서 실행하고, 수정해 사용할 수 있습니다.
공식 배포본을 수정 없이 사용하는 경우에는 포함된 디자인과 비밀번호 입력 기능을
그대로 사용할 수 있습니다. 유료 디자인은 구매한 본인만 사용할 수 있습니다.
공식 배포본을 그대로 다른 곳에 올리거나 파일째 나누어 주는 재배포는 허용하지 않습니다.
쥬나의 디자인이 함께 들어 있기 때문입니다. 아틀리에를 소개할 때는 공식 사이트나
공식 배포처 링크를 공유해 주세요.
파일을 수정해 혼자 사용하는 것은 재배포에 해당하지 않습니다. 다른 사람에게 배포할 수
있는 것은 아래 2번 조건을 모두 지킨 수정본뿐입니다.
판매, 유상 재배포, 유료 기능 추가 등 수익이 생기는 이용은 허용하지 않습니다.

2. 수정본 재배포
아틀리에를 수정해 다른 사람에게 배포하거나 공개 사이트로 제공할 때는 아래 조건을
모두 지켜 주세요.
- 무료로만 배포합니다.
- '쥬나 아틀리에'라는 이름과 원본 주소 https://atelier.zyuna.link/ 를 남깁니다.
- 공식 버전이 아니라는 것을 분명히 밝히고, 다른 이름을 사용합니다.
- 쥬나의 디자인 데이터(무료, 유료 모두)와 유료 디자인 잠금 해제 기능은 빼고 배포합니다.
- 본인의 디자인을 포함해 어떤 유료 디자인도 수정본에 넣지 않습니다.
  수정본을 유료 디자인을 파는 통로로 쓸 수 없습니다.
- 앱의 '이용 범위' 전체와 이 안내를 수정본에도 함께 싣습니다.
수정본의 문의와 유지보수는 수정한 분이 직접 맡아야 합니다.

3. 디자인은 별도 조건 적용
위 허용은 웹 도구 배포 파일에 관한 것입니다. 포함되거나 외부에서 불러오는 디자인,
이미지, 폰트 등은 각 자료의 이용 조건을 따릅니다.
무료 디자인의 출처 표기 등 기존 조건과 유료 디자인의 구매자 이용 조건은 유지됩니다.
위 허용이 디자인 자체를 따로 추출하거나 수정해 재배포할 권한을 부여하는 것은 아닙니다.
유료 디자인의 복호화된 원본, 평문 콘텐츠, 구매 비밀번호를 공개하거나 재배포할
권한을 부여하지 않습니다. 구매한 유료 디자인이 담긴 개인 백업도 공유하지 마세요.

4. 기존 이용 범위
앱의 '이용 범위'에 적힌 디자인 사용, 수정본 재배포와 수익 활동 제한을 함께 지켜 주세요.
유료 기능을 붙이거나 아틀리에용 파일을 판매하는 등 수익 활동을 할 수 없으며,
TRPG와 관계없는 이용도 금지합니다.

5. 외부 라이브러리
THIRD_PARTY_NOTICES.txt에 수록된 라이브러리와 웹 폰트는 각 라이선스를 따릅니다.
웹 도구의 판매 관련 조건이 해당 라이브러리 자체의 라이선스 권리를 변경하지 않습니다.

6. 익명 이용 집계
공식 사이트 https://atelier.zyuna.link/ 는 방문 수와 기능 사용 횟수를 익명으로
집계합니다(Umami 클라우드, 쿠키 없음).
- 수집하는 것: 페이지 방문(주소의 검색어와 # 뒤 부분 제외), 새 방문 또는 재방문,
  핸드아웃 담기, Roll20 복사(핸드아웃, 롤꾸), 이미지 저장(PNG, ZIP과 개수),
  백업과 복원(성공, 실패), 유료 디자인 잠금 해제(성공, 실패, 묶음 이름),
  포스타입 링크 이용(디자인 버전). 쥬나가 제공하는 디자인은 디자인 ID를 함께 보내고,
  커스텀 디자인은 custom으로만 보냅니다. Umami가 기본으로 받는 브라우저 언어,
  화면 크기, 이전 페이지 주소, 페이지 제목도 전송되며, Umami는 접속 정보로
  브라우저 종류, OS, 기기 종류, 국가 등 접속 지역을 집계합니다. Umami는 수집한
  데이터를 익명화하며 개인을 식별할 수 있는 정보는 저장하지 않는다고 밝히고
  있습니다(https://docs.umami.is/docs/faq).
- 보내지 않는 것: 핸드아웃 제목과 본문 등 작업 내용, 검색어, 비밀번호,
  커스텀 디자인의 정보, 백업 파일 내용. 아틀리에는 이름이나 연락처 같은 개인정보를
  받지 않습니다. 접속할 때 IP 주소 같은 통신 정보는 Umami 서버에 전달되며,
  Umami는 수집한 데이터를 익명화한다고 밝히고 있습니다.
- 추적 거부: 브라우저의 추적 거부(Do Not Track) 또는 Global Privacy Control을 켜면
  집계 스크립트를 불러오지 않습니다. 스크립트가 막혀도 사이트는 그대로 동작합니다.
- 배포본: 집계는 공식 주소에서만 동작합니다. 다운로드한 배포본을 다른 주소나
  localhost에서 실행하면 집계 스크립트를 불러오지 않습니다.
